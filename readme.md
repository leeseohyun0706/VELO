# A project VELO

VELO provides many data structure for speed.

It will be developing and provides you absolutely faster experience.

It uses the template syntaxes in c++ for flexible scalability.

#### Developing enviroment

- std=c++17
- macos m1 (currently)
- llvm/clang++
